# 💍 복짱구 ♡ 조짱아 결혼준비 RPG

메이플스토리 **오르비스 하늘정원**을 배경으로 한 횡스크롤 RPG.
두 사람이 직접 맵을 뛰어다니며 🥚 계란과 💧 물방울을 먹어 **오늘의 결혼준비 퀘스트**를 클리어하고,
EXP와 메소를 모아 레벨업하는 게임이에요. 결혼식까지 남은 날이 D-day로 카운트됩니다.

## 실행

`index.html` 을 브라우저로 열면 끝. 설치도 서버도 필요 없어요.

```bash
python3 -m http.server 8000   # http://localhost:8000
```

휴대폰으로 매일 하려면 GitHub Pages(Settings → Pages)에 올리고 홈 화면에 추가하세요.
화면 좌우 하단에 터치 조작 버튼이 나옵니다.

## 조작

| 키 | 동작 |
| --- | --- |
| `←` `→` | 걷기 |
| `Space` / `↑` | 점프 |
| `↓` + `Space` | 아래 발판으로 내려가기 |
| `Z` / `Enter` | NPC · 웨딩 아치와 대화 |
| `Tab` | 복짱구 ↔ 조짱아 전환 (안 쓰는 쪽은 따라다녀요) |
| `C` | 의상 변경 (크림 수트 ↔ 턱시도 / 핑크 드레스 ↔ 웨딩드레스) |
| `Q` | 퀘스트 노트 (퀘스트 · 출석부 · 업적 · 설정) |
| `H` | 조작법 · `ESC` 창 닫기 |

## 게임 방식

- 맵 곳곳에 **오늘 남은 퀘스트만큼** 아이템이 떨어져 있어요. 먹으면 진행도가 +1.
- **담당 캐릭터만 먹을 수 있어요.** 계란·물은 조짱아, 만보·칭찬은 복짱구, 체크리스트는 둘 다 가능.
  → `Tab` 으로 바꿔가며 모으는 게 핵심!
- 목표를 다 채우면 **완료 보너스 +50%** EXP·메소.
- 오늘 퀘스트를 전부 끝내면 꼭대기 **웨딩 아치**가 반짝이고, `Z` 를 누르면 축하 이벤트가 열려요.
- 자정이 지나면 퀘스트가 자동으로 새 하루로 초기화됩니다.

기본 퀘스트

- 🥚 **계란 4개 먹기** (조짱아 · 하루 4개)
- 💧 **물 2L 마시기** (조짱아 · 250ml 컵 8잔)
- 👟 만보 걷기 · 💌 조짱아 칭찬 한마디 (복짱구 · 예시)
- 📋 결혼준비 체크리스트 1개 (함께 · 예시)

## 퀘스트 추가하기

**① 게임 안에서** — `Q` → `＋ 미션 추가`. 이름 · 담당 · 맵에 놓을 아이템(⭐🥚💧💗) ·
목표 개수 · EXP · 메소를 정하면 바로 맵에 아이템이 생겨요. 필요 없는 퀘스트는 🗑 로 삭제.

**② 코드로** — `assets/game.js` 위쪽 `DEFAULT_MISSIONS` 에 한 줄 추가:

```js
{ id: 'jja-stretch', icon: '🧘', item: 'star', name: '스트레칭 10분',
  owner: 'jja', target: 1, unit: '회', exp: 30, meso: 500 },
```

`owner` 는 `'jja'`(조짱아) / `'bok'`(복짱구) / `'both'`(함께, 둘 다 보상).
결혼식 날짜는 퀘스트 노트 → 설정 → 변경, 또는 `CONFIG.weddingDate`.

## 기록

진행 기록은 브라우저 `localStorage` 에 저장됩니다(기기·브라우저마다 별도).
기기를 바꾸기 전에 퀘스트 노트 → 설정 → **내보내기** 로 JSON 백업, 새 기기에서 **불러오기**.

## 파일 구성

```
index.html          게임 화면 + HUD/창 구조
assets/game.js      엔진 (물리 · 아이템 · 퀘스트 · 저장 · UI)
assets/sprites.js   픽셀 캐릭터/아이템/배경 도트 (코드로 그림)
assets/style.css    메이플식 UI 스타일
assets/fonts/       Galmuri 픽셀 한글 폰트 (SIL OFL 1.1, OFL.md 참고)
assets/img/         웨딩 사진 4장 (HUD 초상화에 사용)
```

캐릭터 도트는 웨딩 사진의 의상(크림 수트 · 브라운 타이 · 핑크 튤 드레스 · 웨딩드레스 · 긴 생머리와
진주 헤어핀)을 보고 그렸어요. 두 사람의 결혼을 축하합니다! 🎉
