# 💍 웨딩 퀘스트 — 복짱구 ♥ 조짱아

결혼식 2주 전, 복짱구와 조짱아의 결혼 준비를 메이플스토리 풍 RPG로 만든 웹 게임입니다.
브라우저에서 `index.html` 을 열기만 하면 바로 플레이할 수 있습니다. (설치·빌드 불필요)

```
git clone https://github.com/choyeongah/Claude.git
cd Claude
open index.html        # macOS / 윈도우는 더블클릭
```

## 🎮 게임 구성

### 무대 & 캐릭터
메이플스토리 풍 픽셀 아트 웨딩 아치가 무대입니다. 무대는 16:9 좌표계로 고정되어 있어
화면 크기가 바뀌어도 캐릭터·명패·말풍선 위치가 정확히 맞습니다.

- **복짱구** — 신랑 · 예식준비사
- **조짱아** — 신부 · 다이어트 마스터

이름 명패는 아트웍 위에 무대 좌표로 덧그려서, 확대/축소해도 캐릭터와 정확히 붙어 있습니다.

두 사람은 평소엔 숨쉬듯 움직이고, 클릭하면 대사를 합니다.
퀘스트를 클리어하면 반짝임과 함께 환호 동작을 합니다.

### 🔥 일일 미션 (조짱아 다이어트) — 매일 자정 리셋
| 미션 | 목표 | 보상 |
|---|---|---|
| 🥚 계란 먹기 | 하루 4개 | 1개당 30 EXP |
| 💧 물 마시기 | 하루 2L (250ml × 8잔) | 1잔당 20 EXP |
| ★ 일일 클리어 | 계란 4개 + 물 2L 전부 | 150 EXP · 5,000 메소 |

연속 클리어(스트릭)와 총 클리어 일수가 기록됩니다. 하루를 건너뛰면 스트릭은 0으로 초기화됩니다.

### 📜 결혼준비 퀘스트 (D-14 → D-DAY)
청첩장 발송, 하객 집계, 드레스 가봉, 예복 피팅, 헤어·메이크업 리허설, 예물 수령,
스드메 잔금, 신혼여행 준비, 본식 가방 싸기 등 **18개 퀘스트**가 D-day 순서대로 들어 있습니다.
각 퀘스트에는 상세 체크리스트, 담당자(복짱구 / 조짱아 / 함께), 난이도, EXP·메소 보상이 있습니다.

### 👑 최종 레이드
18개 퀘스트를 모두 클리어하면 **[레이드] 본식 · 결혼식 당일** 이 해금되고,
클리어 시 엔딩 연출(꽃잎 · 팡파레)과 함께 **웨딩 아치 아래 두 사람의 픽셀 컷**이 액자로 열립니다.

### 그 외
- HP / MP / EXP 바, 레벨업 연출, 전직 (예비부부 1차 → 전설의 부부 ★), 메소
- 진행 상황은 브라우저 `localStorage` 에 자동 저장 (하단 `초기화` 버튼으로 리셋)
- 결혼식 날짜는 좌측 상단 D-day 배너의 `날짜변경`(모바일은 ✎) 으로 수정 가능 (기본값: 2주 뒤)
- 효과음 on/off, 모바일 세로 화면 대응
