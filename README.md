# 💍 복짱구 ♡ 조짱아 결혼준비 대작전

메이플스토리 **오르비스(하늘의 도시)** 를 배경으로 한 결혼 준비 일일 퀘스트 게임입니다.
결혼식까지 남은 2주 동안 매일 미션을 클리어하고 EXP와 메소를 모아 함께 레벨업해요.

## 실행 방법

`index.html` 파일을 브라우저로 열면 끝입니다. 설치할 것도, 서버도 필요 없어요.

```bash
# 로컬에서 서버로 열고 싶다면
python3 -m http.server 8000
# → http://localhost:8000
```

휴대폰에서 매일 쓰려면 GitHub Pages로 올린 뒤(저장소 Settings → Pages → 브랜치 선택)
주소를 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.

## 게임 방법

| 요소 | 설명 |
| --- | --- |
| **일일 퀘스트** | `＋` 버튼으로 횟수를 올리면 진행도가 차오릅니다. 잘못 눌렀으면 `−` |
| **EXP / 레벨** | 진행한 만큼 경험치가 들어오고, 목표를 다 채우면 **완료 보너스 +50%** |
| **메소** | 미션 보상. 두 사람 메소를 합친 금액이 '파티 총 메소' |
| **HP** | 오늘의 컨디션 게이지. 오늘 미션을 다 하면 100/100 |
| **연속 일수 🔥** | 자기 미션을 전부 클리어한 날이 며칠 연속인지 |
| **출석부** | D-14부터 결혼식 당일까지 15칸. ⭐ 올클리어 / 🌤 진행중 / 🎯 오늘 |
| **부부 업적** | 계란 30개, 물 50컵, 3일·7일 연속, 10만 메소 등 8종 |

기본 미션은 이렇게 들어 있습니다.

- 🥚 **계란 4개 먹기** (조짱아, 하루 4개)
- 💧 **물 2L 마시기** (조짱아, 250ml 컵 8잔)
- 👟 만보 걷기 / 💌 조짱아 칭찬 한마디 (복짱구 · 예시)
- 📋 결혼준비 체크리스트 1개 처리 (함께 · 예시)

## 미션 추가하기

**① 화면에서 추가 (추천)** — `＋ 미션 추가` 버튼 → 이름·담당·목표 횟수·보상을 입력하면 바로 등록됩니다.
필요 없는 미션은 미션 이름 옆 🗑 로 지울 수 있어요.

**② 코드로 기본값 바꾸기** — `assets/game.js` 위쪽 `DEFAULT_MISSIONS` 배열에 한 줄 추가합니다.

```js
{ id: 'jja-stretch', icon: '🧘', name: '스트레칭 10분', owner: 'jja',
  target: 1, unit: '회', exp: 30, meso: 500 },
```

- `owner` — `'jja'`(조짱아) / `'bok'`(복짱구) / `'both'`(함께, 두 사람 모두 보상)
- `target` — 하루 목표 횟수, `unit` — 화면에 보일 단위
- 결혼식 날짜는 화면의 `날짜 변경` 버튼이나 `CONFIG.weddingDate`에서 바꿉니다.

## 기록 저장

기록은 브라우저의 `localStorage`에 저장됩니다(기기·브라우저마다 따로).
기기를 바꾸기 전에는 화면 아래 **백업 내보내기**로 JSON을 저장하고, 새 기기에서 **불러오기** 하세요.

## 파일 구성


두 사람의 결혼을 축하합니다! 🎉
